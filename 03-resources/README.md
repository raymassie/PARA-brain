# Resources

Reference material: topics and subjects you're interested in, with no end date and no ongoing obligation attached. This is the default home for anything that isn't a project or an area.

Size doesn't matter here. A single fact is a single file (`03-resources/sourdough.md`). When a topic accumulates enough material to need internal structure, it becomes a folder (`03-resources/sourdough/`) and the notes move inside. No threshold to meet before something is allowed in.

No required structure. Use what the topic needs.

Topics are surfaced by theme in `00-wiki`, which indexes across this folder, `01-projects`, and `02-areas`.
