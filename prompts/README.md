# Vault prompts

Read `Librarian.md` and `README.md` before a workflow. Ask in plain language or
name the relevant prompt. These are Markdown instructions for your chosen
assistant; nothing runs in the background.

| Request | Prompt | Effect |
|---|---|---|
| Help customize my vault | `setup.md` | Optional owner profile saved locally with write scope |
| Start a project | `project-intake.md` | Gather goal/dates, then create one project and checklist |
| Process the inbox | `translate.md` | File notes, index them, archive processed originals, refresh Home |
| Refresh project or area status | `project-digest.md` | Update its canonical note/README and Home |
| Review a project | `project-review.md` | Read-only goal, evidence, blocker, and knowledge-gap check |
| Retire finished work | `archive-sweep.md` | Propose candidates; move only with confirmation |
| Check vault health | `audit.md` | Read-only structural, link, and status findings |
| Refresh the front page | `home-digest.md` | Refresh only Home's generated status listing |

Use the workflow's requested scope. A review does not authorize edits, and local
filing does not authorize commits, publication, spending, account access, or
messages to other people. Report unavailable sources and unverified outcomes.
